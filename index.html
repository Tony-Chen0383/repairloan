Supabase Database

門市、人員、待用機、借用紀錄、狀態、Snapshot、Google File ID。PDF 本體與證件影像不進 Database。

Supabase Storage

只存借出 / 歸還 6 面機況照，使用 private bucket；Browser 不持有 service_role。

Supabase Edge Functions

負責 Server Authority、交易狀態、P1+P2 / P3 PDF 封裝、Google Drive OAuth 與歸檔。證件只存在單次 request memory。

Google Drive

每店固定 Folder ID。Final PDF 上傳成功才正式結案；失敗顯示「已歸還・待歸檔」並可重試。

Final PDF

P1 合約＋證件＋簽名；P2 借出前 6 面；P3 歸還後 6 面＋結案。檔名由維修單號＋門市自動產生。

Server Authority

確認借出 / 歸還由 Edge Functions 重新驗證，不信任 Browser 的完成狀態；交易成立時建立 immutable snapshot + SHA-256。
